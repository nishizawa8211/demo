# 採点基準（criteria.md）

> 作成：Planner（元資料：`input/brief.md`）／人のレビュー①を反映済み
> Evaluator はここからスプリント分だけを抜き出して `sprints/<NN-name>/contract.md` を作る。
> 各条件は **観察で合否が判定できる** 文にしている。【必須】は1つでも不合格ならスコアに関係なく不合格。
> 画面のパスは `docs/screens.md` 2 の定義に従う（ログイン `/login.html`、一覧 `/list.html`、詳細 `/detail.html?no=<申込番号>`、ポート 8080）。

---

## 0. 共通ルール

| 項目 | 内容 |
|------|------|
| 合格ライン | **80点以上 かつ【必須】すべて合格** |
| 差し戻し上限 | 3回 |
| 未確認の扱い | 確認できなかった項目は不合格扱い |
| 判定の根拠 | 画面（01〜03）：Playwright MCP（Edge）の snapshot・スクリーンショット・コンソールメッセージ。フロー（04・05）：`flows/` の定義テキスト・手順書の記載 |

### 全スプリント共通の条件（各スプリントの契約に「共通条件」として含める）
| # | 条件 |
|---|------|
| C1 | 【必須】画面・データに実在の社名・人名・番号・システム名・ロゴが無い（架空データのみ） |
| C2 | 【必須】ブラウザのコンソールに JS エラーが出ない（画面スプリントのみ） |
| C3 | 画面文言が日本語 |
| C4 | 秘密情報（実 URL・アカウント・チャット ID・トークン等）がファイルに無い |

## スプリント04 フロー前半（`04-flow-scrape`）

> PAD での実行確認は Evaluator の範囲外。`flows/` の記載内容で判定し、実行は人のレビュー②で確認する。

| # | 合格条件 | 重み |
|---|----------|------|
| 4-1 | 【必須】`flows/` に PAD デザイナーへ貼り付けるアクション定義テキストと、貼り付け・設定の手順書がある | 15 |
| 4-2 | 【必須】手順が `docs/flow.md` 手順0〜4（初期化・Edge 起動・ログイン・一覧取得・全件の詳細取得・CSV 出力）をすべて含む | 20 |
| 4-3 | 【必須】使用セレクターが `docs/screens.md` の業務用 `id` / `data-*` のみで、表示テキスト・行番号・クラス・階層位置に依存せず、デモ操作エリア（`#demo-tools` 等）を参照していない | 20 |
| 4-4 | 画面遷移後に `data-loaded="true"` を待つ手順があり、固定秒数の待機に頼っていない | 10 |
| 4-5 | 詳細への遷移が一覧の「詳細」ボタンのクリックで行われる | 5 |
| 4-6 | CSV が UTF-8（BOM 付き）・見出し行あり・14列（`docs/screens.md` 1-2 の順）で、ファイル名が `申込状況_YYYYMMDD_HHMM.csv` と `latest.csv` | 15 |
| 4-7 | 件数不一致・申込番号不一致・タイムアウト時にメッセージを出して止まる処理がある | 10 |
| 4-8 | 共通条件 C4（ID/PW はダミー値のみ） | 5 |

| # | 合格条件 | 重み |
|---|----------|------|
| 5-1 | 【必須】SharePoint から前回 `latest.csv` を取得する手順が、今回の `latest.csv` 保存より前にある | 15 |

## 人のレビュー②（デモ通し）のチェック項目

スプリント契約の対象外。全スプリント完了後に人が実機で確認する。

| # | 確認項目 | 合格の目安 |
|---|----------|-----------|
| R1 | 直前のリセット手順（`docs/demo-script.md` 1-2：「初期データに戻す」→ フローを1回実行）で、`latest.csv` が初期20件になる | 20件 |
| R2 | 新規2件追加 → フロー実行で、Teams に「新規案件が 2 件あります」と2件の内容が届く | 内容が画面と一致 |
| R3 | 続けて再実行すると「新規案件はありません」が届く | 届く |
| R4 | `latest.csv` が無い状態で実行すると、Teams に投稿されず CSV だけ保存される | 投稿なし |
| R5 | SharePoint の CSV を Excel で開いて文字化けせず、全件 × 14列 | 一致 |
| R6 | フロー実行中、PAD がデモ操作エリアのボタンを押さない | 押さない |
| R7 | フロー1回の実行時間 | 3分以内（目安。持ち時間確定後に見直す） |
| R8 | 台本どおりに通しで実施できる | 持ち時間内 |
| R9 | 画面共有で秘密情報（実 URL・アカウント名等）が映らない | 映らない |
