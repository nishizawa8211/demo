## 5. 補足：フローを決まった時刻に起動するには（質問が出たとき用）

> シーン3の「定期実行にすれば…」に質問が出たときの説明用。デモでは実演しない。

PAD 単体には時刻起動の設定はない。次の3つの方法がある。いずれも**有償ライセンスが前提**で、本デモ（無料の PAD、デザイナーから［実行］）の構成には含まない。ライセンスの名前は変わることがあるので、案内する前に公式ドキュメントで最新の内容を確認する。

| 方法 | 状態 | 主な条件 |
| ---- | ---- | -------- |
| ① クラウドフロー（繰り返しトリガー）から起動 | 正式な機能 | 実行する PC を Power Automate に登録する。職場または学校のアカウントと、デスクトップフローの接続が必要。有人実行は**接続を作った人に Power Automate Premium**、無人実行は **Process プラン（無人 RPA）** が必要 |
| ② スケジュール トリガー（Automation center） | **プレビュー**（本番での利用は非推奨。地域によっては未提供） | **公開済み**のフロー、同じ環境に登録した PC、接続参照、実行モードに応じたライセンスが必要。止まっていた間の回は実行されない |
| ③ Windows のタスク スケジューラから URL で起動 | 正式な機能 | PAD がインストールされていて、ユーザーがサインインしていること。Power Automate Premium（または従量課金の環境）が必要。既定では実行前に**確認のダイアログ**が出る（設定で消せるが、公式はセキュリティ上の危険を警告している）。PAD での有人実行は同時に1本まで |

**PC の状態（有人・無人の違い）**

- 有人実行：ユーザーがサインインしたままの PC で動く。画面を操作するフローなので、実行中は PC を触らない。
- 無人実行：すべてのユーザーがサインアウトしている PC が必要。Windows 10/11 では、ロックされたセッションが1つ残っているだけでも実行できない。接続に使うユーザーにはリモート デスクトップの権限が必要。画面の解像度が作成時と変わると、要素が見つからなくなることがある。

**話すポイント**

- 伝え方の例：「今日はボタンで実行していますが、ライセンスと PC を用意すれば、毎朝決まった時刻に自動で回すこともできます」。
- 条件は「Premium／Process ライセンス、PC の登録、PC の状態」の3点として伝え、断定はしない。

> 注：公式の2つのページで無人実行のライセンスの書き方が揃っていない（「unattended add-on」と「Process plan」）。③の公式ページには、画面がロックされているときの動き方の記載がない。
